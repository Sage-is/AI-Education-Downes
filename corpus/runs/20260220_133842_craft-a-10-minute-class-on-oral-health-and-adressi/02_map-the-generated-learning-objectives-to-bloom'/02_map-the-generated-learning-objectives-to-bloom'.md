## Recommended Taxonomy Distribution

For a brief introductory class, cognitive demand should be weighted toward the **lower-to-middle tiers** of Bloom's taxonomy:

| Bloom's Level | Weight | Rationale |
|---|---|---|
| **Remember** | ~25% | Foundational — learners need to recall key terms and facts |
| **Understand** | ~35% | Core focus — learners should explain and summarize concepts |
| **Apply** | ~25% | Practical — learners use knowledge in guided scenarios |
| **Analyze** | ~15% | Stretch goal — learners compare or distinguish ideas |
| Evaluate | Minimal | Too advanced for a brief intro |
| Create | Minimal | Too advanced for a brief intro |
